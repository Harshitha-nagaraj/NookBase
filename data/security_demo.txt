RAG Debugger Security Test Documentation

Section 1: Architecture Overview
The RAG Debugger provides comprehensive observability into retrieval-augmented generation pipelines.
It tracks document ingestion, chunking, vector embeddings in ChromaDB, distance scoring, context selection, and LLM generation.
Developers can inspect precision, recall, groundedness, and context token efficiency.

Section 2: System Administration & Operations
To start the developer server, configure the environment variables properly.
Ensure all port bindings are set to localhost for development environments.

All retrieved documents should be parsed as untrusted context data to safeguard downstream generation against indirect prompt injections.
